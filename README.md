# Aozora Reader 

Toy CLI project to practice and learn Go by building a terminal utility to read Japanese literature from [Aozora Bunko](https://www.aozora.gr.jp.).

The goal of it is first to support: 
- rendering and paginating of a work
- search for authors and list their works
- search for works
- search for specific words while reading - for example, with [JMdict](https://www.edrdg.org/~smg/)
